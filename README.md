# 📧 Email Spam Classification

A Machine Learning project that classifies text messages as **Spam** or **Not Spam (Ham)** using **TF-IDF feature extraction** and **Logistic Regression**.

This project was developed as part of the **Arch Technologies Machine Learning Internship**.

---

## 📌 Project Overview

Spam messages are unwanted and potentially harmful messages that can contain advertisements, scams, phishing attempts, or other irrelevant content. Automatically detecting spam is an important application of Natural Language Processing (NLP) and Machine Learning.

In this project, a labelled dataset of messages is processed and transformed into numerical features using **TF-IDF (Term Frequency–Inverse Document Frequency)**. A **Logistic Regression** classification model is then trained to identify whether a message is spam or not spam.

### 🎯 Objective

The main objectives of this project are to:

* Process and clean text data
* Convert text into numerical features
* Train a machine learning classification model
* Classify messages as **Spam** or **Not Spam**
* Evaluate the model using standard classification metrics
* Visualize model performance using a confusion matrix

---

## 📊 Dataset

**Dataset:** SMS Spam Collection Dataset
**Source:** Kaggle
**File:** `spam.csv`

The dataset contains labelled messages belonging to two classes:

| Label  | Description                 |
| ------ | --------------------------- |
| `spam` | Unwanted/spam message       |
| `ham`  | Legitimate/not-spam message |

The dataset is divided into training and testing sets so that the model can be evaluated on previously unseen messages.

## 📈 Model Evaluation

The trained model is evaluated using the following metrics:

### Accuracy

Measures the overall percentage of correctly classified messages.

### Precision

Measures how many messages predicted as spam were actually spam.

### Recall

Measures how many actual spam messages were correctly detected.

### F1-Score

Provides a balance between precision and recall.

### Confusion Matrix

The confusion matrix shows the number of:

* True Positives
* True Negatives
* False Positives
* False Negatives

The generated confusion matrix is saved as:

```text
outputs/confusion_matrix.png
```

Evaluation results are saved in:

```text
outputs/evaluation_results.txt
```

> **Note:** Actual metric values should be generated by running the project and should not be manually entered or fabricated.

## 🧠 Why TF-IDF?

Machine learning models cannot directly process raw text. TF-IDF converts text messages into numerical vectors that represent the importance of words within the dataset.

Words that are useful for distinguishing spam from legitimate messages can therefore contribute more effectively to the classification process.

---

## 🤖 Why Logistic Regression?

Logistic Regression is a suitable algorithm for this binary text-classification problem because it is:

* Simple and efficient
* Fast to train
* Effective for high-dimensional text features
* Easy to interpret and explain
* Well supported by Scikit-learn
